Plan de Développement Frontend VentureLink
Phase 1: Préparation et Configuration (Semaines 1-2)
Sprint 1: Configuration de l'Environnement

Initialiser le projet Flutter avec la structure de dossiers MVVM
Configurer Firebase pour le frontend (Authentication, Cloud Messaging)
Mettre en place l'injection de dépendances (GetIt)
Configurer Provider pour la gestion d'état
Configurer les environnements (développement, production)
Mettre en place le CI/CD basique (linting, tests)

Livrables:

Projet Flutter initialisé avec architecture MVVM
Configuration Firebase
Structure de base du projet
Documentation d'installation
